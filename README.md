# Clear Skin: Minimalist Cosmetologist Website

A portfolio demo website for a fictional cosmetologist, built from scratch with plain HTML, CSS and vanilla JavaScript. No frameworks, no libraries.

The brand, the name, the address and all prices are fictional.

## Features

- Light, dark and system theme tokens via CSS custom properties
- Magnetic buttons that follow the cursor and ease back
- 3D card tilt with a cursor spotlight
- Scroll-reveal animations, staggered by order
- Scroll progress bar, hiding header and parallax on one `requestAnimationFrame` loop
- Animated counters and a step line that draws as you scroll
- Skin-type tabs with a sliding pill indicator
- Price accordion that animates with CSS grid rows
- Booking form with validation and an animated confirmation
- Respects `prefers-reduced-motion`

## Run it

Open `index.html` in a browser. No build step.

## Tech

HTML5, CSS3, JavaScript (ES5-compatible, no dependencies). Fonts: Instrument Serif and Manrope from Google Fonts.
